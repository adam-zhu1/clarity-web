What it is

Press one hotkey on any problem on your screen. Read the explanation in seconds. Watch it animated a minute later.

Clarity is a macOS menu-bar app for students. You're stuck on a derivative in a PDF, a recurrence on a slide, a binary search in your editor that returns the wrong index. Press ⌘⇧E, drag a box around the problem, and a small floating window shows a written, step-by-step explanation. Then a short animation, made for that exact problem, plays in the same window. It isn't pulled from a library. A model writes the animation code for your problem and Clarity renders it.

  1. Press ⌘⇧E and drag a box

    Around the problem, in whatever app it's in. PDF, slides, browser, editor. Esc cancels.

    only what's in the box leaves your Mac

  2. Add context, or don't

    A Spotlight-style box slides in with a thumbnail. Type what's confusing you, or press ↓ to re-ask about a recent capture. Enter sends.

    optional

  3. Read, then watch

    The explanation appears in a floating window you can drag anywhere. About a minute later the animation plays beneath it. Ask the same problem twice and the second answer is instant.

    ≈ 8 s to read · ≈ 60–90 s to watch
⌘⇧E
Problem Set 4 · Question 3
Let f(x) = x² sin x. Find f′(π).
Reading the problem…

f is a product: (uv)′ = u′v + uv′.

So f′(x) = 2x sin x + x² cos x.

At π, sin π = 0, so f′(π) = −π².

Install

Two permissions and a hotkey.

Clarity lives in the menu bar with no dock icon. macOS asks for two permissions the first time, each followed by a relaunch.

Download Clarity.dmg
RequiresmacOS 14 or later, Apple Silicon
BackendDocker Desktop, plus API keys for Gemini, Anthropic and Voyage AI
AccountsNone. Recents stay on your Mac.

  1. Download and drag to Applications

    Open Clarity.dmg, drag Clarity into Applications, and open it.

  2. Let macOS open it

    Clarity isn't notarized yet, so macOS 15 blocks it once. Go to System Settings → Privacy & Security, scroll down, and click Open Anyway.

  3. Grant Screen Recording, then relaunch

    Needed for the region screenshot. Approve the prompt, then quit and reopen Clarity from the menu bar.

  4. Press ⌘⇧E once, grant Input Monitoring, relaunch

    Needed for the global hotkey. Approve it, relaunch, and the hotkey is live.

  5. Start the backend

    The coordinator and agent service run on the same Mac. Until a bundled installer ships, you run them from the repository.

    Follow the setup guide for the full walkthrough: Docker and the manim-worker image, MinIO, MongoDB Atlas, API keys, then one command per service. docs/SETUP.md →
    git clone https://github.com/s0hamjain/Clarity.git
cd Clarity

  6. Capture something

    ⌘⇧E, drag a box around a problem, type any context, press Enter.

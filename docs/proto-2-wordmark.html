Problem set 4 · Q3

Let f(x) = x² sin x. Find f′(π).

⌘⇧E
f′(π)
why does the x² term vanish?
↓↵
Clarity
Reading the problem…

Both x² and sin x depend on x, so this is the product rule: differentiate one factor at a time and add.

f′(x) = 2x sin x + x² cos x

Now put x = π into each term.

  • 2x sin x → 2π · sin π = 2π · 0 = 0
  • x² cos x → π² · cos π = π² · (−1)

So nothing happened to the x² — the first term died because sin π is zero. At any other point it would still be there.

f′(π) = −π²
